# 50K 星火奖 · Three.js 开发接入说明

版本：`50k-en-badge-zh-ui-2026-09-29`。

本包为 **50k 英文徽章＋中文 UI＋最新版绿色水晶开屏**。供开发将 Three.js 模型、动画和交互接入现有网站的弹窗；随包页面用于效果对照和运行参考，不要求替换整站。本包不包含 100k、Blender 工程、Figma 文件或完整交互录屏，未发布线上。

## 1. 本版交付范围

- 英文 50k GLB，使用原始模型与内嵌渐变，主体为黄绿色，星形为浅色，凹槽为较深绿色。
- 背面英文：Your Models Have Been Printed / 50,000 Times / MakerWorld。
- 中文 UI：星火奖、您的模型累计被打印 50,000 次!、恭喜获得「星火奖」、获得日期、分享、确认。
- 开屏已替换为 2026-09-29 最后提供的 `视频.mp4` 黑底版本。网站使用中心方形裁切、缩放及去音轨后的版本，没有对新视频再次抠绿幕或修改颜色。
- 保留原有 2.65 秒揭晓时间轴、旋转、回正、流星、光尘与背部微光。50k 独立配置，不覆盖 100k。
- 请以本包为准；旧交付包及线上链接可能尚未包含此次开屏更新。

## 3. 查看和启动

直接打开 `preview/50k星火奖预览.html` 查看效果。修改源码时，在包根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory threejs
```

- 效果页：`http://127.0.0.1:8765/`
- 材质调试：`http://127.0.0.1:8765/badge-lab.html`
- 时间轴调试：`http://127.0.0.1:8765/?debug=1`

源码通过 HTTP/HTTPS 加载，不直接双击 `threejs/index.html`。Three.js r180 和 GSAP 3.13.0 已在 `vendor/`，无需 npm 或外部 CDN。核心 Three.js 和 addons 必须使用同一版本。

## 4. 接入开发自己的弹窗

| 文件 | 职责 |
| --- | --- |
| `BadgeGLB.js` | GLB 加载、尺寸归一化、材质应用、资源释放 |
| `BadgeThemes.js` / `BadgeThemeConfig.js` | 四区域材质和 50k 专属 green 配置 |
| `BadgeGLBEnvironment.js` | HDRI → PMREM，以及 ACES / AgX 渲染设置 |
| `BadgeUnlockSequence.js` / `BadgeUnlockConfig.js` | 开屏到徽章揭晓的状态机和时间轴 |
| `BadgeOpeningVideo.js` | 首帧准备、静音循环、暂停恢复、失败回退和清理 |
| `BadgeUnlockEffects.js` / `BadgeBackdropEffects.js` | 揭晓特效、流星、光尘、微光，独立于徽章材质 |
| `BadgeStudio.js` / `app.js` | 灯光和完整接线示例、渲染循环、拖动及旋转 |
| `index.html` / `style.css` / `ui.js` | 中文 UI 结构与行为参考 |

当前是可运行模块源码，**不是可直接 mount 的框架组件或多实例 SDK**。以 `app.js` 为接线参考，纳入宿主的弹窗与生命周期。

1. 准备容器、Canvas、相机、renderer、后处理与 UI 元素。
2. 加载 GSAP（当前读取 `window.gsap`）、GLB 和 HDRI，再创建 `BadgeUnlockSequence`；保留资源准备完成后才允许揭晓的逻辑。
3. 保持单一渲染循环，更新时间轴、模型和独立特效；保留播放期间禁用交互、结束后恢复交互的状态。
4. 绑定拖动、旋转、回正、分享和确认。宿主业务层接管弹窗关闭、领取记录、达成判断和分享渠道。
5. 关闭 / 卸载时停止渲染循环，取消事件和 ResizeObserver，释放 sequence、GLB、HDRI、composer 及宿主拥有的 renderer。`badgePresentation.close()` 只关闭开屏模块，不等于销毁整个页面。

当前使用全局 DOM 查询：`.award-screen`、`.award-copy`、`.award-actions`、`.controls`、`#scene`、`#rotate`、`#reset`、`#award-title`、`.award-message`、`.award-date`、`#award-date`、`#share-award`、`#confirm-award`、`#action-status`。保留对应结构，或改为由宿主传入元素引用。同页多实例需先隔离容器、状态和配置。

参考页在初始化成功后暴露：

```js
window.badgePresentation.setTheme('green'); // 本版仅交付 green 主题
window.badgePresentation.getTheme();
window.badgePresentation.reset();           // 停止自动旋转并回正
window.playBadgeUnlock();                   // 重播；播放中重复触发会被忽略
```

这些接口由 `app.js` 创建，单独导入 GLB 模块不会自动生成。资源路径默认相对于页面；接入构建工具 / 子目录后统一调整 GLB、HDRI、视频、SVG 和模块路径，跨域加载需配置 CORS。

## 5. 动画、材质与 UI 基准

正常揭晓约 2.65 秒：0 秒收缩，0.28 秒穿梭，0.72 秒星芒，1.05 秒闪光，1.16 秒显示 GLB，1.70 秒上移，1.98 秒显示 UI，2.48 秒开放交互。减少动态模式约 0.65 秒，不使用穿梭 / 白闪且默认不自动旋转。

开屏是黑底 MP4，**没有 Alpha 通道**。保留深色背景及现有 `mix-blend-mode: screen`，视频静音循环、内联播放，裁切比例配置为 1.15。原片约 5.04 秒的循环长度与点击后 2.65 秒的揭晓时间轴是独立的。加载失败 / 超时回退到程序化晶体。

默认 ACES、曝光 0.91、输出 sRGB，支持 AgX 配置。HDRI 用于模型反射，不要用统一材质覆盖所有表面；保留星形、底面、文字、凹槽的层次及 Body_Edge 的反光抑制。

| Green 区域 | color | roughness | metalness | envMapIntensity |
| --- | --- | --- | --- | --- |
| Body | #ffffff | 0.270 | 1 | 1.00 |
| Star | #ffffff | 0.225 | 1 | 0.90 |
| Text | #ffffff | 0.205 | 1 | 1.00 |
| Recess | #ffffff | 0.430 | 1 | 0.78 |

表中颜色是乘到原始模型基色 / 渐变上的乘数；白色用于保留 GLB 的绿色和浅色星形，并非把模型变白。边缘还有专门处理，最终以模块源码为准。本包仅配置 green，不含 Silver / Gold / Blue / Black 换色验收版本。厚度、倒角和字形来自 GLB。

流星每 3 秒轮换三条上方路径；光尘靠近徽章，桌面 14 颗、移动端 9 颗，背部微光透明度 0.048。特效不复用徽章材质。

调试页支持正视 / 侧视 / 背视、OrbitControls、坐标轴、包围盒和材质调节。应用配置只存到当前浏览器的 `spark-award:50k:glb-themes:v1`；正式发布给所有用户需导出并更新配置文件。不要使用 100k 的存储键或覆盖其资源。

当前 UI 为中文，日期为访问者本地今日日期，跨午夜 / 返回前台刷新，不是服务器的真实获奖时间。英文 UI 由宿主国际化层适配，英文徽章素材无需再次更换。

分享参考逻辑生成 1080×1440 PNG，优先系统分享，降级为下载 / 文字分享。确认参考逻辑回正、清理开屏并显示“已确认”；实际关闭业务弹窗、跳转及发奖记录由宿主接入。前端 `badgeawarded` 事件不代表服务端已授奖。

## 6. 检查与交付边界

本次交付检查：真实 GLTFLoader CPU 加载、11 个网格和 2 张贴图、80 次材质应用无累积漂移、独立特效材质、HDRI 解析、重载与释放；日期、分享 / 取消 / 降级、确认；视频首帧、循环、暂停恢复、失败回退和清理；新 MP4 全 121 帧解码及显示范围检查。

打包时另核对 JavaScript 语法、模块 / HTML 本地引用、源码及原始 GLB 一致性、内嵌预览视频一致性、文件哈希和 ZIP 完整性。GPU 视觉与实体手机性能尚未验收；请开发在目标浏览器 / WebView 检查正反面反光、首帧和过渡、旋转按钮、分享、横竖屏、减少动态模式、关闭重进和资源释放。

修改源码后，在包根目录运行 `python3 tools/build-preview.py` 重建预览。`文件校验.json` 为此次交付快照，源码变更后需要重新生成。100k 保持独立，后续等级单独交付。
