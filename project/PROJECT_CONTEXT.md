# 项目交接 · 2026-09-29

这是 MakerWorld 打印成就奖牌和开屏交互项目。用户希望在不同电脑的 Codex 中继续编辑，每次做一个等级，已确认版本不被后续版本影响。

## 当前版本

100k：银色英文徽章，背面 Your Models Have Been Printed / 100,000 Times / MakerWorld。中文界面，英文 GLB 已替换；此前完成开发包。

50k：黄绿色英文徽章，背面对应 50,000 Times。已接入独立预览，中文 UI 和分享图片为 50,000。沿用 100k 动画和布局，保留 50k 内嵌原色。默认主题 green，颜色乘数白色；已完成 2026-09-29 开发交接包。最新开屏来自用户最后提供的黑底视频，网站使用 720×720、24fps、约 5.04 秒无声循环版本；不再使用之前的绿幕输入或旧抠像视频。

两版 GLB 都是提供的原文件，模型已经内嵌所需渐变贴图，无需 Blender 才能运行网页。运行时使用的文件哈希见 docs/source-snapshot-2026-09-29.json。

## 已确认的交互与视觉方向

- 徽章薄金属、浅浮雕、清晰正反面英文文字；白光、星形层次与凹槽区分，避免侧面刺眼反光和过强背光。
- 100k 开屏保持约4.04秒原确认版；50k 改用约5.04秒最新版黑底水晶视频。两者均为黑底 MP4 配 screen 混合，不是透明Alpha视频。
- 点击触发原有2.65秒揭晓时间轴，2.48秒开放操作。播放中不能重复触发；减少动态模式约0.65秒。
- 拖动、自动旋转、回正；分享和确认按钮保留当前比例、位置、渐变。
- 流星每3秒在三条奖牌上方路径循环；近奖牌光尘桌面14/移动9；微光0.048。特效独立于模型材质。
- 今日日期按访问者本地时区，午夜/回到前台刷新。UI不是后台真实获奖记录。
- 分享生成1080×1440图片；确认仅当前端状态，业务领取/弹窗关闭/跳转需开发接入。

## 重要模块

BadgeGLB.js：GLB适配、归一化、生命周期。
BadgeThemeConfig.js / BadgeThemes.js：分区材质和存储。
BadgeUnlockSequence.js / BadgeUnlockConfig.js：状态机和时间轴。
BadgeOpeningVideo.js、BadgeUnlockEffects.js、BadgeBackdropEffects.js：开屏及独立特效。
app.js：renderer/相机/后处理/循环/控件接线。
index.html / style.css / ui.js：中文UI、日期、分享。

当前模块依赖特定DOM和window.gsap；不是任意宿主可直接mount的SDK。关闭开屏不等于释放整个renderer，在SPA中必须适配组件卸载。100k保留旧SVG调试工作流，正式使用GLB；50k不包含该旧工作流。

## 验证情况与限制

100k英文版：正面几何与旧版一致，其余材质/贴图、动画/UI未改变。GLTFLoader的CPU集成、材质切换、重载和资源释放通过。
50k：11材质批次、2贴图、归一化尺寸、材质编辑、重载与释放检查通过；日期/分享/确认模拟行为通过。100k原文件哈希未变。
当前环境浏览器自动化内核及Chrome启动失败，不能声称完成GPU视觉或实体手机验收。在新电脑如浏览器可用，应优先打开两版实际确认。
