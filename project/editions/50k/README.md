# 50k 星火奖 · 独立版本

本版为黄绿色英文 50k 徽章，UI 为中文，打印次数为 50,000。参考预览用于逐级确认，尚未发布线上。

- `threejs/`：独立可运行源代码，入口 `index.html`，调试页 `badge-lab.html`。
- `threejs/assets/Spark_Award_50K.glb`：提供的原始英文 GLB，几何与内嵌颜色贴图不改。
- `BadgeThemeConfig.js`：50k 专属 `green` 配置，白色乘数保留原色和渐变；沿用 100k 的曝光、粗糙度分层及侧边反光抑制。
- `BadgeThemes.js`：独立存储键 `spark-award:50k:glb-themes:v1`，不读写 100k 的调试设置。
- 开屏视频、2.65 秒时间轴、控件布局与旋转交互沿用确认版；流星与光尘采用接近白色的淡绿调。
- 降级图为 50k 原始正面 SVG，中文弹窗与分享图片都显示 50,000。

在本目录运行 `python3 -m http.server 8766 --bind 127.0.0.1 --directory threejs` 后，访问 `http://127.0.0.1:8766/`。运行 `python3 tools/build-preview.py` 可生成独立离线预览。

100k 的 `dist/`、预览和已交付包均保留；两个等级各自修改，禁止用此目录覆盖 100k。源代码为独立基准副本，不会随另一等级的实验改动自动更新。

只加载已交付的 50k 模型与渐变，不使用额外的字体重建文字。此次没有制作新的开屏视频或 Figma 稿。宿主弹窗生命周期与业务行为仍由开发接入。
